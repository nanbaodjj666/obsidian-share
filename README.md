## 说明

- 原始格式为 Obsidian Markdown。Obsidian 的双链与图片嵌入语法**已全部转成标准 Markdown 相对链接**，在 GitHub 网页上直接可读、可点，图片不会裂
- **中英对照课件（lecture1–8）是单文件 HTML**：517 页课件截图已 base64 内嵌在文件里，手机浏览器直接打开即可，点图片可全屏放大。GitHub 不渲染 Obsidian 的 `![[图片]]` 语法，所以这部分不发 md、改发 HTML
- quiz 里的「课件定位」直接跳到对应讲义的 `#sN` 锚点（N = 课件页码）
- 按「科目」分子文件夹只是为了方便浏览，文件本身是平的
- 内容由脚本单向同步，本仓库不接受 PR（笔误请开 issue）
- 仅限学习交流使用
