# 三、描述性研究

> 来源：流行病学.docx · 2026-10-13 由 docx 转 Markdown（保留原大纲层级 / 表格 / 公式转为 LaTeX）
> 医学内容请以教材、指南与任课教师为准复核，不可用于临床决策。

## 1.描述性研究descriptive study：
Ⅰ概念：利用常规监测记录或通过专门调查获得的数据资料，按照不同地区、不同时间及不同人群特征进行分组，描述人群中有关疾病或健康状况以及有关特征和暴露因素的分布状况，在此基础上进行比较分析，获得疾病三间分布的特征，进而获得病因线索，提出病因假设。
Ⅱ种类：（13年简答题）
①现况研究：又称横断面研究cross sectional study或患病率研究prevalence study ，通过对特定时点（或期间）和特定范围内的人群中的疾病或健康状况和有关因素的分布状况的资料收集、描述，从而为后续研究提供病因线索。
②生态学研究ecological study：又称相关性研究correlation study，它是在群体的水平上研究某种暴露因素与疾病之间的关系，以群体为观察和分析的单位，通过描述不同人群中某因素的暴露状况和疾病的频率，分析该暴露因素与疾病之间的关系
③病例报告case report：对临床上某种罕见病的单个病例或少数病例的详细介绍，属于定性研究的范畴
④病例系列分析case series analysis：对一组相同疾病的病人临床资料进行整理、统计、分析、总结并得出结论
⑤个案研究case study：又称个案调查，是指到发病现场对新发病例的接触史、家属及周围人群的发病或健康状况以及可能与发病有关的环境因素进行调查，以达到查明所研究病例的发病原因和条件，控制疫情扩散及消灭疫源地，防止再发生类似疾病的目的，研究对象一般为传染病人。
⑥历史资料分析：是研究疾病的三间分布特征、疾病危险因素和评价疾病防制措施效果的重要资料和信息来源；研究者通过回顾性调查，提取和利用相关机构的日常工作的记录、登记、各类日常报告、统计表格、疾病记录档案等历史资料，进一步开展统计分析，最终获得研究结果。
⑦随访研究 follow-up study：也称纵向研究，是通过定期随访，观察疾病和健康状况或卫生事件在一个固定人群中随着时间推移的动态变化情况。可以是预定的时间段内执行的纵向调查，也可以是规律性实施的横断面研究。也可用于疾病自然史的研究。
Ⅲ特点：
①以观察为主要研究手段，不对研究对象采取任何干预措施（实验研究要采取干预）
②暴露因素的分配不是随机的，且在研究开始时一般不设立对照组（分析性研究要设立对照组）
③暴露与结局的时序关系无法确定，仅可进行一些初步的比较分析，但可为后续的分析性或实验研究提供线索
Ⅳ用途：
①描述疾病或健康状况的分布以及发生发展规律：从时间、地区、人群分布三个方面，对正在调查的或已有的资料进行描述，揭示疾病或健康状况的分布以及发生发展规律。
②获得病因线索，提出病因假设：疾病或健康状况在不同时间、地区、人群中的分布差异可能是由某些原因造成的，通过比较疾病或健康状况在三间分布中的差异，可为后续研究提供病因线索，提出病因假设。
## 2.现况研究：
概念：通过对特定时点（或期间）和特定范围内的人群中的疾病或健康状况和有关因素的分布状况的资料收集、描述，从而为后续研究提供病因线索。
从时间上来说，现况研究收集的是某特定时间断面的资料，故又称横断面研究cross sectional study。
从观察分析指标来说，由于该研究得到的频率指标一般为特定时间内调查群体的患病率，故又称为患病率研究prevalence study。
特点：
①在设计阶段不设对照组：但在资料处理与分析时，可根据暴露的状态和是否患病的状态进行分组比较
②现况研究的特定时间：这个特定时点并不一定是某年某月的某一特定时间，对于群体中的每一个个体来说，特定时点所指的具体时间可能不同。例如，在一个人群中调查高血压的患病情况，对于每个个体来说，特定时点是指测量血压、诊断是否为高血压的时间。同样也可以是病人入院时间、出院时间等。
③在确定因果关联时受到限制：现况研究揭示的暴露与疾病之间的统计学联系，仅为建立因果联系提供线索，是分析性研究的基础，不能据此做出因果推断。
理由如下：1.无法确定暴露与疾病的时间顺序关系（此点不是绝对的，④点为特殊情况）；2.研究对象一般是存活期较长的病人，而病程较短的病人很难被包括在一个短时期的研究中。由于存活期长和存活期短的病人，在许多特点上不同，研究人员很可能将影响存活的因素当作影响发病的因素（现患病例-新发病例偏倚）
④对研究对象固有的暴露因素可以作因果推断：这些研究对象固有的暴露因素有：性别、种族、血型、基因型等，这些因素在疾病发生之前就存在，且不会因是否患病而发生改变。那么在排除和控制了可能存在的偏倚的情况下，现况研究可以提供相对真实的暴露与疾病的时间先后顺序的联系，从而进行因果推断。
⑤用现在的暴露来替代或估计过去情况的条件：符合以下前提条件时，可用现在的暴露来替代或估计过去情况：1.现在的暴露或暴露水平与过去的情况存在良好的相关关系，或已被证明变化不大；2.已知研究因素的暴露水平的变化趋势或规律，可据此趋势或规律来估计过去的暴露水平；3.回忆资料的暴露或暴露水平极不靠谱，则可用现在的暴露资料来估计过去的暴露情况
⑥定期重复现况研究可以获得发病率资料：$\text{该时期的发病率}=\frac{\text{两次现况研究患病率之差}}{\text{两次研究的时间间隔}}$ ，前提：两次现况研究之间的时间间隔不能太长，要求该时期的发病率变化不大和病程稳定（本质上还是用的$\text{“患病率}=\text{发病率}\times \text{病程”}$ 这个公式）
类型：普查、抽样调查
普查：census
概念：全面调查，是指在特定时点或时期内、特定范围的全部人群（总体）作为研究对象的调查。
目的：①早发现、早诊断、早治疗，如妇女的宫颈癌普查；
②了解慢性病的患病及急性传染病的疫情分布，如高血压普查和针对疫区开展的普查；
③了解当地居民健康水平，如居民膳食与营养状况调查；
④了解人体各类生理生化指标的正常值范围，如青少年身高、体重的测量
优点：
①不存在抽样误差
②可用同时调查目标人群中多种疾病或健康状况的分布情况
③能发现目标人群中的全部病例，实现“三早”预防的同时，全面描述疾病的分布与特征，提供病因线索
缺点：
①不适合患病率低且无简便易行诊断手段的疾病（抽样调查同样不适合患病率太低的疾病，患病率太低的疾病要用病例对照研究）
②工作量大，容易漏查
③调查工作人员调查技术和检查方法的熟练程度不一，难以统一和标准化，因此较难保证调查质量
④人力、物力资源耗费大，费用高（费时费力费钱）
抽样调查：sampling survey
概念：通过随机抽样的方法，对特定时点、特定范围内人群的一个代表性样本进行调查，以样本统计量来估计总体参数所在范围。
目的：通过对样本中的研究对象的调查研究来推论其所在总体的情况
优点：
①节省时间、人力和物力资源
②调查范围小，调查工作可以做得细致
缺点：
①设计、实施与资料分析均比普查复杂
②资料的重复和遗漏不易发现
③不适合变异过大的研究对象或因素，以及需要普查普治的疾病
④不适合患病率过低的疾病
随机抽样的优点/原因：①保证样本代表性 ②降低抽样误差 ③节约调查成本和时间
（3）现况研究 设计与实施的步骤
$\begin{matrix}\text{设计}\text{（}\text{确定研究目的}\to \text{确定研究类型}\to \text{确定研究对象}\to \text{确定样本含量和抽样方法}\text{）} \\ \to \text{实施}\text{（}\text{资料收集}\to \text{数据整理与分析}\text{）}\end{matrix}$
研究目的：了解疾病或健康分布状况 or 开展群体健康检查 or 考核防制措施效果 or 探索病因或危险因素
研究类型：普查or抽样调查
确定样本含量n：
Ⅰ样本含量n的影响因素：①预期患病率p ②对调查结果精确性的要求：容许误差d越大，n越小 ③显著性水平α：α越大，z值越小，n越小
Ⅱ计算（以单纯随机抽样为例）
$n=\frac{pq}{{s}_{p}^{2}} \text{，令}{s}_{p}=\frac{d}{{z}_{1-\frac{\alpha}{2}}} \text{则}n=\frac{pq}{{\text{（}\frac{d}{{z}_{1-\frac{\alpha}{2}}}\text{）}}^{2}}=\frac{pq*{z}_{1-\frac{\alpha}{2}}^{2}}{{d}^{2}}\text{（}\text{仅适用于}np>5\text{）}$
$np\leq 5\text{时，用}Poisson\text{分布的方法来估算}$
p为预期患病率，q=1-p，d为容许误差，${z}_{1-\frac{\alpha}{2}}$为显著性检验的统计量（${z}_{1-\frac{\alpha}{2}}$和${z}_{\frac{\alpha}{2}\text{其实一样}}$）
当α=0.05时，${z}_{1-\frac{\alpha}{2}}=1.96$
当α=0.01时，${z}_{1-\frac{\alpha}{2}}=2.58$
当d=0.1p时，且α=0.05时，${z}_{1-\frac{\alpha}{2}}=1.96\approx 2$，则$n=\frac{4pq}{0.01{p}^{2}}=400\frac{q}{p}$
d=0.2p时，且α=0.05时，${z}_{1-\frac{\alpha}{2}}=1.96\approx 2$，则$n=\frac{4pq}{0.04{p}^{2}}=100\frac{q}{p}$
若抽样调查的分析指标为计量资料，$ n=\frac{4{s}^{2}}{{d}^{2}} \text{（}np>5\text{）}$
抽样方法类型：
①简单随机抽样simple random sampling：从总体N个对象中，利用抽签或其他随机方法（如随机数字）抽取n个，构成一个样本
②系统抽样systematic sampling：按照一定顺序，机械地每隔若干单位抽取一个单位的抽样方法。
③分层抽样stratified sampling：先将总体按某种特征分为若干次级总体（层），然后从每一层内进行单纯随机抽样，组成一个样本。
1.各层抽样比例相同的称为按比例分配proportional allocation分层随机抽样
2.各层比例不同的称为最优分配optimum allocation分层随机抽样
④整群抽样cluster sampling：将总体分为若干群组，抽取其中部分群组作为观察单位构成样本，这种抽样方法称为整群抽样。
1.若抽到的群组中全部个体均为调查对象，称为简单整群抽样simple cluster samping
2.若对抽到的群组内全部个体进行再次抽样，对再次抽样后的部分个体进行调查，称为二阶段抽样two stages sampling
⑤多阶段抽样multistage sampling：将抽样过程分阶段进行，每个阶段使用的抽样方法不同，即将各种抽样方法结合使用，在大型流行病学调查中常用。（如：人口普查）
抽样方法的抽样误差大小比较：$\text{整群抽样}>\text{简单随机抽样}>\text{系统抽样}>\text{分层抽样}$
各种抽样方法的优缺点：

| 抽样方法 | 优点 | 缺点 |
|---|---|---|
| 单纯随机抽样 | 简单，是其他方法的基础 | 当总体数量很多时，编号、抽样麻烦，抽到的个体分散而导致资料收集困难 |
| 系统抽样 | ①可以在不知道总体单位数的情况下使用 ②在现场人群中容易实施 ③代表性较好 | 若总体各单位的分布有周期性趋势，而抽样的间隔恰好与此周期或其倍数吻合，则可能使样本产生偏性 |
| 分层抽样 | ①提高精确度，能保证总体中每一层都有个体被抽到 ②除了能估计总体的参数，还能分别估计各层内的情况 | 分层较多时，调查和分析较麻烦 |
| 整群抽样 | ①易于组织、实施，节省人力物力 ②群间差异越小，抽取的群越多，则精确度越高 | 抽样误差大通常在单纯随机抽样样本量估算的基础上再增加1/2 |
| 多阶段抽样 | 充分利用各种抽样方法的优势，克服各自的不足，且节省人力物力 | 抽样前要掌握各级调查单位的人口资料及特点 |

现况研究的用途：
①提供病因线索，
②确定高危人群，这是早发现、早诊断、早治疗的首要步骤
③评价疾病监测、预防接种等防制措施的效果。通过规律地重复开展现况研究，既可以获得开展其他研究的基线资料，又可以通过比较不同时期患病率的差异，对防制策略、措施的效果进行评价。
常见偏倚及其控制
偏倚bias：是指从研究设计与实施到数据处理和分析的各个环节中产生的系统误差，以及结果解释、推论中的片面性导致的研究结果与真实情况之间出现的偏向性的差异，进而导致对暴露与疾病之间联系的错误描述。
偏倚就是系统误差，就是测量值与真实值之间的差值。偏倚越小，即差值越小，测量值越接近真实值。
$\text{误差}=\text{随机误差}\text{（}\text{抽样误差}\text{）}+\text{系统误差}\text{（}\text{偏倚}\text{）}$
随机误差不可避免，但可以通过多次测量来减小
系统误差可以避免，通过标准化的测量工具、测量方法来校正

| 主要偏倚类型 | 子类型 | 描述 |
|---|---|---|
| 选择偏倚 | 导致研究样本缺乏代表性，而使研究结果无法外推 |   |
|   | 随意抽样 | 主观选择研究对象，误将随机抽样当作随意抽样 |
|   | 随意更换抽样方法 | 抽样方法确定后，又中途任意变换 |
|   | 无应答偏倚 | 调查对象不合作或种种原因不能或不愿意参加调查，从而降低了应答率，若应答率< 70%，就难以用调查结果估计整个研究总体的状况 |
|   | 幸存者偏倚 | 所调查的研究对象均为幸存者，无法调查到死亡的人，研究结果具有一定片面性和局限性，不能全面反映真实情况 |
| 信息偏倚 | 报告偏倚 | 调查对象回答不准确 |
|   | 回忆偏倚 | 调查对象对过去的暴露史、疾病史等回忆不清 |
|   | 调查偏倚 | 调查人员有意识地重视或忽略某些特征 |
|   | 测量偏倚 | 测量工具、检验方法不正确，化验操作不规范等导致 |
| 混杂偏倚 | 数据分析中，混杂因素的存在导致结果与实际情况存在出入 |   |

偏倚值取值范围 0 - 1 ,越接近1 偏倚越大，越接近0 偏倚越小
偏倚的控制：
①严格遵照抽样方法的要求，确保抽样过程中随机化原则的切实实施
②提高研究对象的依从性和受检率
③正确选择测量工具和检测方法，包括调查表的编制
④组织好研究工作，调查员一定要经过培训，统一标准和认识
⑤做好资料的复查、复核等工作
⑥选择正确的统计分析方法，注意辨析混杂因素及其影响
现况研究的优缺点
优点：①因随机抽样，研究结果有推广意义，以样本估计总体的可信度较高
②有来自同一群体自然形成的同期对照组，使结果具有可比性
③一次调查可同时观察多种因素，是病因探索过程不可或缺的
缺点
①收集的信息通常只能反映调查当时个体的疾病与暴露状况，难以确定因果的先后顺序
②不能获得发病率资料，除非在一个稳定的群体中，连续进行同样的现况调查
③研究对象中一些人可能处于所研究疾病的潜伏期或临床前期而被误判为正常人，使研究结果发生偏倚，低估该研究人群的患病率。
## 3.生态学研究：
概念：
又称相关性研究correlation study，它是在群体的水平上研究某种暴露因素与疾病之间的关系，以群体为观察和分析的单位，通过描述不同人群中某因素的暴露状况和疾病的频率，分析该暴露因素与疾病之间的关系。
特点
①最基本特征：在收集资料时，不是以个体为观察和分析的单位，而是以群体为单位。
②通过描述不同人群中某因素的暴露情况与疾病频率来分析该因素与疾病的关系，但无法得知个体的暴露与效应（疾病）之间的因果关系
③是探索病因线索的一种常用方法，然而其提供的信息是不完全的，只是一种粗线条的描述性研究
用途：
①提供病因线索，提出病因假设：常用于慢性病的病因学研究，或环境变量与人群疾病或健康状关系的研究
②评估人群干预措施的效果：通过描述人群中某些干预措施的实施状况及某些疾病的发病率或死亡率的变化，经比较和分析，对干预措施进行评价；在疾病监测中，可用生态趋势研究来估计监测疾病的发展趋势，为制定疾病预防和控制的策略和措施提供依据。
类型：生态比较研究、生态趋势研究
生态比较研究ecological comparison study：观察不同人群或地区某种疾病的分布，然后 根据疾病分布的差异，提出病因假设。一般情况下，这种研究不需要暴露情况的资料，也不需要复杂的资料分析方法。
生态趋势研究ecological trend study：连续观察不同人群中某因素平均暴露水平的变化与某种疾病的发病率、死亡率变化的关系，了解其变动趋势；通过比较暴露水平变化前后疾病频率的变化情况，来判断某因素与某疾病的联系。
优点：
①节省时间、人力、物力，出结果快
②为病因未明的疾病提供病因线索，进而深入研究。这是生态学研究最显著的特点
③对于个体暴露剂量无法测量的情况，生态学研究是唯一可供选择的研究方法
④当研究因素暴露在一个人群中变异范围小时，暴露与疾病的关系难以测量，此时可使用多个人群比较的生态学研究，如饮食结构与若干癌症的关系研究
⑤适合进行人群干预措施的评价
⑥在疾病监测工作中，应用生态趋势研究可估计某种疾病发展的趋势
缺点：
①生态学谬误ecological fallacy：是由于生态学研究以各个不同情况的个体“集合”而成的群体为观察和分析的单位，以及存在的混杂因素等原因而造成研究结果和真实情况不符，是生态学研究最主要的缺陷。
②难以控制混杂因素：无法将潜在的混杂因素造成的影响分离出来
③难以确定两变量之间的因果联系
造成生态学谬误的原因
①缺乏暴露与结局联合分布的资料
②无法控制可疑的混杂因素
③相关资料的暴露水平只是近似值或平均水平，并不是个体的真实暴露水平。
## 4.现况研究和生态学研究的异同点
异：观察分析单位：一个是个体，一个是群体
同：都是观察性研究，都用来描述人群中疾病或健康状况及暴露因素的分布状况，为进一步调查研究提供线索
## 5.描述性研究和病例对照研究的异同
异
①病例对照研究可以检验病因假设 ②病例对照研究设计时分为病例组和对照组，描述性研究在研究设计阶段不分组。
同
①均可产生病因假设 ②都是流行病学最基本的研究方法 ③都属于观察法，没有人为干预 ④因果论证能力弱
