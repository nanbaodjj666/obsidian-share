# 五、队列研究

> 来源：流行病学.docx · 2026-10-13 由 docx 转 Markdown（保留原大纲层级 / 表格 / 公式转为 LaTeX）

## 基本概念
队列研究cohort study：是将人群按是否暴露于某可疑因素以及暴露程度分为不同组，追踪其各组的的结局，比较不同组之间的结局频率的差异，从而判定暴露因素与结局之间有无因果关联以及关联大小的一种观察性研究方法。
暴露exposure：是指研究对象接触过某种待研究的物质（如重金属），或具有某种待研究的特征（年龄、性别、遗传性状等）或行为（如吸烟）。暴露是本研究需要探讨的因素，暴露可以是有害的，也可以是有益的。（简单说：对一个或多个队列进行随访，追踪其结局，分析暴露与结局的关系，就是队列研究。）
队列cohort：某一特定范围内的人群称为一个队列。
出生队列birth cohort：在某特定时期内出生的一组人群，称为出生队列
暴露队列exposure cohort：具有某种共同暴露或共同特征的一组人群，称为暴露队列
固定队列fixed cohort：人群都在某一固定时间或一个短时期之内进入队列，之后对他们进行随访观察，直至观察期终止，不再加入新成员。队列规模会因为成员死亡、失访或发生研究的结局事件而逐渐减小。
动态队列dynamic cohort：在某队列确定后，原有的队列成员可以不断推出，新的观察对象可以随时加入，即在观察期内，队列成员是动态变化的。
危险因素risk factor：又称为危险因子，泛指能引起特定不良结局outcome（如疾病）发生，或使其发生的概率增加的因子，包括个人行为、生活方式、环境和遗传等多方面的因素。危险因素的反面称为保护因素protective factor，两者统称决定因素determinant factor或影响因素。
## 基本原理（类似于把定义再详细扩写）
是在一个特定人群中选择所需的研究对象，根据目前或过去某个时刻是否暴露于某个待研究因素（危险因素或保护因素），或其不同的暴露水平而将研究对象分成不同的组，如暴露组和非暴露组，高剂量暴露组和低剂量暴露组等，随访观察一段时间，检查并登记各组人群待研究的预期结局的发生情况，比较各组结局的发生率，从而评价和检验研究因素与结局的关系。
## 特点
①属于观察法：队列研究中的暴露不是人为给予的，不是随机分配的，而是在研究之前已客观存在的，不受研究者意志决定，这是队列研究与实验研究的重要区别。
②设立对照组：一般在设计阶段会设立对照组（与现况研究的区别），也可以在资料分析阶段设立对照组。对照组可与暴露组来自同一人群，也可来自不同的人群（详细看对照选择）。
③由因及果：在结局发生前就确立了研究对象的暴露状况，而后探求暴露因素与结局的关系。
④检验暴露与结局的因果联系能力较强：能够准确计算出结局的发生率，估计暴露人群发生某结局的危险程度，因此判断因果关系的能力较强。
## 研究目的
①检验病因假设：一次队列研究可检验一种暴露与一种或多种结局之间的因果关联（一因多果）
②评价预防措施效果：当某些预防措施（暴露）不是人为给予的，而是研究对象的自发行为时（即符合观察法，若人为给予就属于实验法），可用队列研究来评价这种预防措施的效果。
③研究疾病自然史：观察人群暴露于某因素后，疾病逐渐发生、发展，直至结局的全部过程，从人群的角度研究疾病发生和发展的自然规律。
④新药的上市后监测（易忘）
## 研究类型：根据研究对象进入队列时间及终止观察时间的不同，分为三类
①前瞻性prospective cohort study：研究对象的分组（暴露与对照）是根据研究对象现时的暴露状况而定，此时研究的结局还没出现，需要前瞻观察一段时间才能得到
②历史性historical cohort study：研究对象的分组（暴露与对照）是根据研究开始时，研究者已掌握的有关研究对象在过去某个时点的暴露状况的历史资料做出的；研究开始时，研究的结局研究出现了，不需要前瞻性观察。又称回顾性队列研究retrospective cohort study或非即时性队列研究
③双向性ambispective cohort study：在历史性队列研究的基础上，继续前瞻性观察一段时间，是将前瞻性队列研究与历史性队列研究结合起来的一种设计模式。也称混合型队列研究。

|   | 优点 | 缺点 |
|---|---|---|
| 前瞻性队列 | 直接获取暴露与结局的一手资料，资料偏倚小，结果可信 | 所需人群样本大、观察时间长、人力物力耗费大 |
| 历史性队列 | ①资料搜集与分析所需时间短 ②性质仍然是由因及果 ③省时、省力、出结果快 | ①资料积累时未收到研究者的控制，内容上未必符合要求 ②需要足够完整可靠的过去某段时间的研究对象的暴露与结局的历史记录或档案材料 |
| 双向性队列 | 兼有两者优点，并一定程度上弥补了各自缺点 |   |

## 基本实施步骤
$\text{确定研究因素}(\text{暴露因素})\to \text{确定研究结局}\to \text{确定研究现场和研究人群}\to \text{确定样本量}\to \text{资料搜集与随访}\to \text{质量控制}$
确定研究因素：在描述性研究和病例对照研究的基础上确定
确定研究结局：可以是最终结果（发病、死亡），也可以是中间结局（血清的变化）；可以是定性，也可以是定量的；可以是负面的（死亡），也可以是正面的（康复）
确定研究现场：①由足够数量的符合条件的研究对象 ②当地的领导重视，群众理解和支持 ③当地文化教育水平较高，医疗卫生条件较好，交通较便利 ④除上述条件外，还考虑现场的代表性
## 研究人群的选择：
暴露人群exposure population
①职业人群：研究某种可疑的职业暴露因素与疾病或健康的关系，必须选择相关职业人群作为暴露人群。在历史性队列研究中，常选用职业人群作为暴露人群。
②特殊暴露人群：研究某些罕见的特殊暴露的唯一选择。一般不易或不允许使用前瞻性队列研究，常使用历史性队列研究。如原子弹爆炸的受害者，或接受过放射线治疗的人，以研究射线与白血病的关系
③一般人群：某一区域范围内的全体人群，选择其中暴露于欲研究因素的人做暴露人群。如美国弗明汉地区的心血管队列研究
④有组织的人群团体：是一般人群的特殊形式，如学校、工会等。利用他们的组织系统，可有效收集随访资料。他们的职业和经历往往相同，增加了可比性。
对照人群control population：对照选择的基本要求是尽可能保证其与暴露组的可比性（即控制变量，除了研究因素外的其他特征和因素尽可能相同）
①内对照internal control：先选择一组研究人群，将其中暴露于所研究因素的对象作为暴露组，其余非暴露者作为对照组。即选定的研究对象内部包括了暴露组和对照组。当暴露变量是定量变量时，可按暴露剂量分为若干等级。
②外对照external control：当选择特殊暴露人群或职业人群作为暴露人群时，需要在该人群外寻找对照。
③总人口对照total population control：外对照的一种，利用整个地区现成的发病或死亡统计资料，即以全人群为对照，而不是与暴露组平行地设立一个对照组进行调查。适用于总人群中暴露者比例很小的情况。
④多重对照multiple control：同时使用上述两种或两种以上的形式选择多组人群作对照，减少只用一种对照所带来的偏倚，增加结果可靠性。

|   | 优点 | 缺点 |
|---|---|---|
| 内对照 | ①省事②暴露组和对照组的可比性较好 | 随访观察时会受到暴露组的影响 |
| 外对照 | 随访观察时不会受到暴露组的影响 | 麻烦，需要另外寻找 |
| 总人口对照 | 对比资料容易获得 | ①资料粗糙，不精确或缺乏想要比较的详细资料，可比性差。②对照中可能包含暴露人群 |
| 多重对照 | 减少偏倚，增强结果可靠性 | 增加工作量 |

## 样本量大小的确定
计算样本量n时需考虑的问题
①暴露组和对照组的比例：一般对照组的样本量不宜少于暴露组，一般是等量。
②失访率：假设失访率为10%，则$\text{实际样本量}=\text{计算出的样本量}\times \left(1+10\%\right)$
影响样本量n的因素（${p}_{0}$、d、α、β都和 n 反着来）
①一般人群（对照人群）中所研究疾病的发病率 ${p}_{0}$ ：${p}_{0}$ 越小，n越大
②暴露组与对照组人群发病率之差 d ：d越大，n越大
③显著性水平α：α越小，n越大
④效力/效能/把握度 1-β：1-β越大，β越小，n越大
计算公式
${n}_{\text{暴露组}}={n}_{\text{对照组}}=n=\frac{{\left({Z}_{1-\frac{\alpha}{2}}\sqrt{2\hat{pq}}+{Z}_{\beta}\sqrt{{p}_{0}{q}_{0}+{p}_{1}{q}_{1}}\right)}^{2}}{{\left({p}_{1}-{p}_{0}\right)}^{2}}\text{（}\text{应用前提：}{n}_{\text{暴露组}}={n}_{\text{对照组}}\text{）}$
${p}_{1}\text{：暴露组预期发病率} \text{；}{p}_{0}\text{：对照组预期发病率} \text{；}q=1-p\text{；} \hat{p}\text{是}{p}_{1}\text{和}{p}_{0}\text{的平均值} \text{，}\hat{q}\text{同理}$
${p}_{1}=RR \text{∙}{p}_{0} $

### （1）人时（不是很重要）：
person time$ \text{人时}=\text{观察人数}\times \text{观察时间}$ ，常用的人时单位是人年。用于描述观察对象的暴露经历
计算方法：
①精确法：知道每个人的精确的观察时间（精确到天）
②近似法 ：不知道每个队列成员进入和退出队列的具体时间，或样本量很大，对人时计算的精确性要求不高时使用。用该年的平均人口数作为该年的观察人年数
③寿命表法：将观察当年进入队列的个人算作1/2人年，失访或出现终点结局的也算作1/2人年
### （2）率：（危险度指的就是累积发病率和发病密度）
①累积发病率 CI：如果研究人群的数量较大且比较稳定（固定队列），则无论其发病强度大小和观察时间长短，均可用观察开始时的人口数作分母，以整个观察期内的发病或死亡人数为分子，计算某病的累积发病率或累积死亡率。取值范围 0到1，反映的是特定时间内的发病风险risk 。报告累积发病率时必须说明累积时间的长短（n年累积发病率）。
$\text{累积发病率}=\frac{\text{观察期内发病人数}}{\text{观察开始时的人数}}$
注意事项：1.一定要报告累积时间，即n年累积发病率 2.累积发病率的分母是观察开始时的人数，这是和发病率的区别，发病率的分母是易感人数，这两者是有区别的。
②发病密度 ID：如果队列研究观察时间较长，很难做到研究人口的稳定（动态队列），此时使用发病密度。分母为观察人时，分子为观察期内发病人数，反映的是速率rapidity，取值范围 0到无穷大。
$\text{分布密度}=\frac{\text{观察期内发病人数}}{\text{观察总人时数}}$
③标化死亡（发病）比 SMR：当研究对象数目较少，结局事件的发生率（死亡率或发病率）比较低时。
$SMR=\frac{\text{研究人群中的}\text{观察死亡数}}{\text{以标准人口死亡率计算出的}\text{预期死亡数}}$
④标化比例死亡（发病）比 SPMR：若某单位的历年人口资料不能得到，而仅有死亡人数、死因、日期和年龄，则可改算标化比例死亡比。计算方法是以全人口中某病因死亡占全部死亡的比例乘以某单位实际全部死亡数而得到的某病因的预期死亡数。
$\text{①}\frac{\text{全人口因某病死亡人数}}{\text{全人口死亡总数}}\times \text{某单位实际全部死亡数}=\text{某单位某病因预期死亡数}$
$\text{②}SPMR=\frac{\text{某单位}\text{某病因实际死亡数}}{\text{某单位}\text{某病因预期死亡数}}$
标化比的流行病学意义和相对危险度RR类似，将分母的预期死亡是用全人口数据算的，视作一般人群，则“某人群死于某病因的危险为一般人群的xx（标化死亡比）倍”
#### 累积发病率和发病密度的区别和联系

|   |   | 累积发病率 | 发病密度 |
|---|---|---|---|
| 同 |   | 都用于描述人群的发病情况 |   |
| 异 | 使用条件 | 数量较大且稳定的人群（固定队列） | 人口不稳定、观察时间长、存在失访的人群（动态队列） |

### （3）效应测量指标：RR是危险度比/率比，AR是危险度差，一个除法，一个减法。队列研究最大的优点是可以直接计算结局的发生率，因而能直接计算RR和AR，就可以直接评价暴露效应。
①相对危险度relative risk RR：

|   | 危险度比risk ratio RR | 率比rate ratio RR |
|---|---|---|
| 测量指标不同 | 累积发病率之比 | 发病密度之比 |
| 具体计算出的数值不同 |   |   |
| 公式一样 | $RR=\frac{{I}_{e}}{{I}_{0}}$ |   |
| 流行病学意义一样 | 暴露组发病或死亡的危险是对照组的多少倍。RR越大，说明暴露的效应越大，暴露与结局关联的强度越大。$RR<1$ 说明是保护因素 ；$RR>1,\text{说明是危险因素，}$RR=1说明暴露与结局无关联 |   |

我们计算的RR是点估计值，考虑到抽样误差的存在，还需要计算置信区间，常用95%CI
$\text{①}Var(lnRR)=\frac{1}{a}+\frac{1}{b}+\frac{1}{c}+\frac{1}{d}(abcd\text{是在资料整理表格里},Var\text{是方差的意思}\text{）}$
$\text{②}RR\text{的}95\%CI={e}^{lnRR\text{的}95\%CI}={e}^{lnRR\pm 1.96\sqrt{Var\text{（}lnRR\text{）}}}={e}^{lnRR\pm 1.96\sqrt{\frac{1}{a}+\frac{1}{b}+\frac{1}{c}+\frac{1}{d}}}$
$exp(n)\text{就是}{e}^{n}\text{，}{e}^{lnX}=X$
②归因危险度attributable risk AR：又叫特异危险度/危险度差risk difference/超额危险度excess risk，是暴露组与对照组发病率或死亡率之差的绝对值，表示危险特异性归因于暴露因素的程度。
$AR={I}_{e}-{I}_{0}$
$\text{由于}RR=\frac{{I}_{e}}{{I}_{0}} ,\text{即}{I}_{e}=RR\times {I}_{0},\text{代入上式可得}AR={I}_{0} (RR-1) $
RR与AR的区别
RR 说明暴露者发生相应疾病的危险是非暴露者的多少倍；AR 是指暴露人群与非暴露人群相比，所增加的疾病发生数量，如果暴露因素消除，就可减少这个数量的疾病发生。前者具有病因学意义，后者更具有疾病预防和公共卫生意义。RR大说明病因联系强，AR大说明预防所取得的社会效果较大。
③归因危险度百分比 AR%：又称病因分值etiologic fraction EF，是指暴露人群中的发病或死亡中归因于暴露的部分占全部发病或死亡的百分比。
$AR\%=\frac{{I}_{e}-{I}_{0}}{{I}_{e}}\times 100\%=\frac{AR}{{I}_{e}}\times 100\%=\frac{RR-1}{RR}\times 100\%$
暴露人群的中的发病或死亡有百分之多少可以归因于暴露因素
④人群归因危险度population AR PAR：指总人群中发病或死亡中归因于暴露的部分。
⑤人群归因危险度百分比 PAR%：指总人群中发病或死亡归因于暴露的部分占全部发病或死亡的百分比。也称为人群病因分值population etiologic fraction PEF
PAR和PAR%的大小既与RR和AR有关，也与人群中暴露者比例有关。
$PAR={I}_{t}-{I}_{0}$
$PAR\%=\frac{{I}_{t}-{I}_{0}}{{I}_{t}}\times 100\%=\frac{{P}_{e}\left(RR-1\right)}{{P}_{e}\left(RR-1\right)+1}\times 100\%$
${I}_{t}\text{是全人群的发病率或死亡率} \text{；}{I}_{0}\text{是非暴露组的发病率或死亡率；} {P}_{e}\text{是人群中某种暴露者的比例}$
RR和AR说明暴露的生物学效应，而PAR和PAR%说明暴露对全人群的危害程度，以及消除这个因素后该人群的发病率或死亡率可能降低的程度。
⑥剂量效应关系dose-effect relationship的分析
若某种暴露存在剂量效应关系，即暴露的剂量越大，效应越大，则该暴露作为病因的可能性就越大。具体分析方法：先列出不同暴露水平下的发病率，然后以最低暴露水平组为对照，计算其他各暴露水平组的RR和AR。必要时对危险度或率的变化作趋势性检验。
## 常见偏倚及其控制：
### 选择偏倚selection bias：
选择偏倚即研究对象的选择不当，如缺乏代表性（暴露组不能代表暴露人群）、暴露组与对照组没有可比性（控制变量没做好），而导致研究结果偏离真实情况。
①最初选定参加研究的对象中有人拒绝参加
②在进行历史性队列研究时，有些人的档案丢失或记录不全
③研究对象由志愿者组成，他们往往是健康的或由某种倾向和习惯的
④错误分类偏倚：有些研究对象是早期病人，但在研究开始时未能发现
⑤易感性偏倚（补充）：有些因素可能直接或间接的影响观察人群或对照人群对所研究疾病的易感性，导致某因素与某疾病间的虚假联系，由此而产生的偏倚称为易感性偏倚。易感性偏倚的典型例子是在对职业性疾病研究中的健康工人效应。当在对某一有毒物质对作业工人的健康危害进行研究时，可能会发现暴露于该有毒物质者的死亡率或某些疾病的发病率反而比一般人群低。原因是接触此类有毒物质者，由于工作性质的需要，其健康水平就比一般人群高，或者对毒物的耐受性比一般人群要强，因而对某些疾病的易感性低所致。
预防方法：
①正确的抽样方法，尽可能遵守随机化原则
②严格按规定的标准选择研究对象
③提高研究对象的依从性和应答率
④进行历史性队列研究时，要求目标人群的档案资料齐全。丢失或不全的记录必须在一定限度之内，否则应谨慎使用
⑤如有志愿者加入或有选定的研究对象拒绝参加，则应了解他们的基本情况之后，与正常参加人群进行比较，如果基本特征无差异，则可认为选择偏倚较小，否则不能忽视。
### 失访偏倚follow-up bias：
本质上属于选择偏倚，由于研究对象失访造成暴露与结果之间的关系被歪曲。
补救方法：①查询失访者是否死亡以及死亡原因；如果失访者与未失访者对于所研究疾病的死亡率接近，则可认为他们之间的发病率可能也接近。②比较失访者和未失访者的基线资料，两者的基线特征越相似，则出现不同疾病发病率的可能性越小。这两个只是补救方法，是对失访者和未失访者间发病率差异的一种推测，不是测量。
控制失访偏倚的最好方法还是尽可能减少失访。
### 信息偏倚information bias：
指在获取暴露、结局或其他信息时所出现的系统误差或偏差。又称错分偏倚misclassification bias ，如判断有病为无病，判断有暴露为无暴露。
来源：使用的仪器不精确、测量方法不稳定、询问技巧不佳、检验技术不熟练、医生诊断水平不高或标准不明确、记录错误甚至造假。
非特异性错分偏倚：错分偏倚以同样的程度发生于观察的各组，结果只会影响诊断的准确性，不太影响两组或多组之间的相对关系，他们的相对危险度一般会比实际情况更接近1。
特异性错分偏倚：错分偏倚发生于一组而不发生在另一组，或两组错分的程度不同，则结果可能比实际相对危险度高或低，效应的估计值被高估或低估。
预防方法：
①选择精确稳定的测量方法、调准仪器、严格实验操作规程、同等地对待每个研究对象、提高临床诊断技术、明确各项标准、严格按规定执行
②做好调查员培训，提高询问调查技巧，统一标准，并进行有关责任心和诚信度地教育。
选择偏倚中的错误分类偏倚与信息偏倚的错分偏倚要区别：在选择研究对象的时候,如果标准不统一也可发生选择偏倚,即研究对象的错误分类偏倚。而在收集研究信息过程中发生的暴露或结局错误分类偏倚属于信息偏倚，即错分偏倚。
### 混杂偏倚confounding bias：
当我们研究某个因素与某种疾病的关联时，由于某个既与疾病有关，又与所研究的暴露因素有关的外来因素的影响，掩盖或夸大了所研究的暴露因素与疾病之间的联系，造成的偏倚称为混杂偏倚。这个第三因素就是混杂因素，它在暴露组和对照组的分布是不均衡的，性别、年龄是最常见的混杂因素。
控制方法：（限制、匹配、分层分析）
①研究设计阶段，对研究对象作某种限制（如某一年龄组、某性别），以便获得同质的样本
②在对照选择时，采用匹配的方法，保证两组在一些重要变量上的可比性
③资料分析阶段，首先应根据混杂的判断标准（既与疾病有关，又与暴露因素有关）来判断混杂存在的可能性。混杂的处理一般采用分层分析、标准化或多因素分析的方法
## 队列研究的优点与局限性：
优点：
①由于暴露数据是在结局发生之前收集的，并且都是按照设计由研究者亲自观察得到（无回忆偏倚），因此资料完整可靠，信息偏倚较小。（资料完整可靠、信息偏倚小，且无回忆偏倚）
②可直接获得暴露组和对照组的发病率或死亡率，进而直接计算RR和AR等反映疾病危险程度的指标，直接分析暴露的病因作用。（直接发病率，直接RRAR，直接暴露的病因作用）
③有助于了解疾病的自然史，可分析一种病因与多种疾病的关系。（自然史+一因多果）
④因在前，果在后，其检验病因假设的能力较强，一般可证实因果联系。（检验假设+证实因果）
局限性：
①不适合发病率很低的疾病的病因研究。
②由于随访时间长，研究对象不易保持依从性，容易产生失访偏倚。
③在随访过程中，未知变量引入人群（如环境变化、引入其他干预措施），或人群中已知变量的变化（如戒烟者吸烟、原吸烟者戒烟），都可使结局受到影响，使分析复杂化。
④耗费人力、物力、财力、耗时长。
